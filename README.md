# Polymarket Bot

Python CLI scripts for buying/selling on [Polymarket](https://polymarket.com) and browsing
its markets, order books, and your open orders/positions.

- **Start here:** [docs/PROJECT_OVERVIEW.md](docs/PROJECT_OVERVIEW.md) — what each script does and how they fit together.
- **Buying walkthrough:** [docs/BUYING_GUIDE.md](docs/BUYING_GUIDE.md)

```bash
pip install -r requirements.txt
cp config.yaml.example config.yaml
python3 test_connection.py
```
